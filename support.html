SUPPORT

Help us improve SkillUP.

Please report incorrect answers, unclear wording, broken links, accessibility problems or technical errors.

What to include

  • The page name and school year.
  • The topic, lesson or exact question wording.
  • What happened and what you expected.
  • A screenshot only when it does not show personal information.

Do not include a child’s full name, school, contact details, writing draft or other private information.

Report an issue on GitHub

GitHub requires an account. Reports are public, so remove all personal information before submitting.

No GitHub account?

Create a privacy-safe report below, copy it, and send it to the parent, teacher or organisation that shared SkillUP with you. They can forward it to the website owner.

Quick technical checks

  1. Refresh the page once.
  2. Check that JavaScript and local storage are allowed.
  3. Try a current version of Chrome, Edge, Firefox or Safari.
  4. If saved progress looks wrong, clear only this website’s stored data and restart the lesson.

Clearing site data permanently removes locally saved progress and writing drafts.
